**STG tooling · embedded security · small desktop apps**

C++ · C# · Rust · Python

I build small, finished tools for niche problems — mostly around shoot-'em-up games, plus a few hardware and desktop projects.

## More tools

- **[ESP32 Shocker Bridge](https://github.com/vihithr/ESP32-Shocker-Bridge)** — maps HTTP events to an opto-isolated TENS device, with a Frida hook GUI.
- **[CAVE BGM Replace Tool](https://github.com/vihithr/PC_Cave_Shmups_BGM_Replace_Tool)** — extract and replace WAV entries in CAVE PC shmup sound archives.
- **[STGB Unpacker](https://github.com/vihithr/Old-Shooting-Game-Builder-Game-Unpack-Tool-STGB)** — unpack and restore pre-Steam Shooting Game Builder projects.
- **[JS Idle Shmup](https://github.com/vihithr/JSIdleShmup)** — a browser bullet-hell / idle game in a single HTML5 canvas page.
- **[FastAPI + Caddy + systemd](https://github.com/vihithr/FastAPI-Caddy-Systemd-OneKey)** — a one-command FastAPI deployment template for Debian/Ubuntu.
- **[FastAPI MUD](https://github.com/vihithr/FastAPI-SIMPLE-MUD)** — a WebSocket MUD RPG with JWT, SQLAlchemy and an Arch ECS sidecar.
- **[Smart Bookmark Organizer](https://github.com/vihithr/smart-bookmark-organizer)** — LLM-assisted bookmark classification for Chrome and HTML exports.
- **[Antigravity Context Monitor](https://github.com/vihithr/antigravity-context-monitor)** — a context-window and compaction monitor for the Antigravity desktop app.
